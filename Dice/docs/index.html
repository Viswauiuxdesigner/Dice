📱 Android Compatibility & Execution Architecture Report

Comprehensive analysis of running this car data helper workflow on Android devices.

A. What WORKS in Plain Android Chrome

  • Opening static HTML/JS pages hosted on GitHub Pages or local storage.
  • DOM extraction & normalization logic running inside an active page.
  • Saving & retrieving mapping configs / extracted car JSON in localStorage.
  • Form filling logic executing within an active page or iframe.
  • Manual form review and manual submission by user.

B. What DOES NOT WORK in Plain Android Chrome

  • Cross-tab auto-filling: Standard Android Chrome isolated web tabs cannot inspect or inject JS into each other due to browser same-origin policies.
  • Chrome Desktop Extension Manifest V3: Plain Android Chrome does not support desktop Chrome extensions out of the box.
